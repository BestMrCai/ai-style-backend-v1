# 即梦生成发型封面方案（v4）

## v3 实测结果：发型跑偏

衣服、背景、皮肤都对了，但 **清爽层次碎盖被生成成了寸头**。原因：

1. 发型只有最后一句英文，权重被前面长段描述（服装/背景/光）稀释；
2. “short textured crop, short sides” 中“short”信号过强，模型只抓住了“短”；
3. 缺少明确长度（厘米）与“不是寸头”的排除。

v4 改法：每款先用 **中文写清发型长度与形状**，再补英文；非寸头款的负向里直接排除“寸头”。
